## Daily view

Work Hub shows current work, return points, evidence-backed decisions, follow-ups, source freshness and automatic job results. Open a linked BB conversation in its original model, group related conversations, focus several items, or mark a follow-up fulfilled.

## Local foundation

The portable SQLite ledger and outbound source collectors live outside BB. The plugin supplies the working surface, BB conversation capture and grouped due-date notifications. Selected source excerpts are analyzed by the configured model service.

## Qualification preview

Coverage is bounded and analysis is asynchronous. Inspect the source scopes and backlog before relying on the follow-up list. Live review and error-fixer triggers are not enabled.
